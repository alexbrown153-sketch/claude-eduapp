Future roadmap ideas
1. Gamify the points so that the user can purchase modifications to the app with their points. Examples include change the colour scheme, introduce different fonts, allow the purchase of an avatar which is visible throughout, allow purchases to modify the avatar. Consider other examples which make the experience fun.
2. I want to be able to seed the question generation with sample question sets by uploading a file of sample questions.
3. Allow the participant to input their name so their experience can be personalised. Use their name throughout the app.
4. introduce a dashboard which shows strengths and weaknesses across topics possibly as a heatmap.
5. Before starting a new session on "all topics" highlight which topics will be included, expressed as a percentage of total questions
6. Add a custom session length where the user specifies how many questions or length of time they wish to have
7. Allow user to cancel out of a test back onto the home page.
8. On the home page under "daily practice" - give the user an indication of what their strengths and weaknesses are
