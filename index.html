      Import questions

      Structured exam papers (e.g. "Tiffin Test N: Mathematics") are recognised automatically — only the maths section is imported, using the paper's own answer key and worked explanations. Questions involving a fraction, symbol, or a chart/graph/diagram that can't be extracted or shown reliably as text are skipped, not guessed — see below for exactly which ones and why. Plainer PDFs also work, formatted like "Q: ..." per question (an "A: ..." answer is optional; left out, it's worked out from the question where possible, and flagged as a guess otherwise).
